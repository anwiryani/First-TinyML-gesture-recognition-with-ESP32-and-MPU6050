This is my first completed TinyML mini project focused on recognize three hand movements: scrolling up, scrolling down, and idle
The model is trained and tested using Edge Impulse with 120 files dataset gestures that include: 
1. scroll up (40 files, variate the speed and range movement)
2. scroll down (40 files, variate the speed and range movement)
3. idle (40 files, variate the sensor position)
